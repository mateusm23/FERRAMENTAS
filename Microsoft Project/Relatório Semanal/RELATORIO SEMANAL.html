Relatório Semanal de Obra
Gere relatórios de acompanhamento de obra a partir de dois cronogramas do MS Project exportados em XML — o cronograma base (R00) e o cronograma atual (R01). A ferramenta compara datas, calcula desvios, monta quadros de justificativas e prévia das próximas atividades, tudo pronto para exportar em PDF.
Como usar
📂
Abra os cronogramas no MS Project
R00 (base inicial) e R01 (revisão atual)
💾
Exporte o R00 como XML
Arquivo → Salvar Como → Projeto XML (.xml)
🔄
Repita para o R01
Salve o cronograma atualizado também em .xml
📝
Preencha as informações
Nome da obra, período, logos e foto
⬆️
Faça upload dos XMLs
Os dois arquivos salvos no passo anterior
📄
Exporte em PDF
Preencha justificativas e imprima
Dica: Não tem dois arquivos separados? Salve o mesmo cronograma como R00 antes de fazer qualquer ajuste, e depois salve a versão atualizada como R01. A comparação sempre usa R00 como linha de base e R01 como revisão atual.
